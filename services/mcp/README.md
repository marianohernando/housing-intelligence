# services/mcp

Servidor MCP del producto DATA: tools sobre servicios de dominio, nunca SQL libre.

Desde MCP-001 (D-225) tiene 5 herramientas de solo lectura por stdio (`buscar_zonas`, `que_falta`, `explicar_zona`, `encontrar_zona` y `fuentes_de_datos`). Se arranca con `make mcp`. Uso, configuración de clientes y pruebas: `docs/04_technical_architecture/32_mcp_server.md`. Contratos de diseño: `docs/04_technical_architecture/10_mcp_contracts_detailed.md`.
