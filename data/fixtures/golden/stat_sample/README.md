# stat_sample — fixtures de tablas estadísticas

Recorte real de las tablas del Instituto de Estadística de la Comunidad de Madrid (CC BY 4.0):
último periodo; Madrid, La Acebeda y Ajalvir; total regional; una zona estadística; tres códigos
postales de Madrid para el alquiler. Coherente con `admin_sample` (mismos municipios).
Regenerar con `uv run python scripts/build_stat_fixtures.py` (requiere Bronze descargado).
