# PUBLIC → PRO → DATA Flywheel

## PUBLIC
Genera:
- utilidad;
- usuarios;
- escenarios;
- preferencias;
- señales agregadas de demanda;
- contenido SEO.

## PRO
Compra:
- análisis territorial;
- gap;
- oportunidad;
- producto;
- sensibilidad;
- proyecto/parcela.

## DATA
Compra acceso programático a:
- métricas;
- rankings;
- análisis;
- tools MCP;
- features territoriales.

## Flywheel
Más PUBLIC → mejor comprensión de demanda (agregada y protegida) → mejor PRO → más ingresos → más datos/modelos → mejor PUBLIC.

## Regla
Nunca vender perfiles personales.
