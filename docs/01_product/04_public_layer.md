# Capa PUBLIC

## Objetivo
Ser suficientemente útil como para que una persona no necesite pagar.

## Motivo estratégico
Más utilidad pública → más adopción → mejores señales agregadas → mejor inteligencia PRO.

## Funciones nucleares
1. Crear perfil.
2. Entender affordability.
3. Recomendar zonas.
4. Explicar el porqué.
5. Mostrar mapa.
6. Reality Check.
7. Comparar alternativas.
8. Ayudas.
9. Coste real.
10. Compra vs alquiler.
11. Evaluar vivienda concreta.
12. Aprender de feedback y descartes.

## Datos generados
- búsquedas;
- cambios de criterio;
- motivos de rechazo;
- zonas guardadas;
- perfiles agregados;
- elasticidad precio/tiempo;
- necesidades no cubiertas.

Nunca se vende el perfil individual.
