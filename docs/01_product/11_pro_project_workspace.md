# PRO Project Workspace

## Entrada
- dirección;
- referencia catastral;
- parcela;
- archivo;
- documentación;
- idea de producto.

## Contenido
- mapa;
- capas;
- documentos;
- análisis;
- comparables;
- escenarios;
- notas;
- comentarios;
- outputs;
- historial.

## Chat contextual
El chat conoce:
- proyecto;
- área;
- documentos;
- métricas;
- escenarios.

Ejemplo:
> “¿Qué producto encaja mejor aquí si quiero alquiler familiar?”

## Aislamiento
Cada workspace pertenece a un tenant y respeta permisos.
