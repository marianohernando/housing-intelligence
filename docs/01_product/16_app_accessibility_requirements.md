# Product Accessibility Requirements

El producto que analiza accesibilidad debe ser accesible él mismo.

## Baseline
Objetivo: WCAG 2.2 AA para superficies web principales.

## Requisitos
- navegación por teclado;
- focus visible;
- labels accesibles;
- contraste;
- no depender solo de color;
- reduced motion;
- tamaño de targets;
- screen reader;
- formularios/chips anunciados;
- errores comprensibles;
- mapas con alternativa textual/lista.

## Map
La información crítica mostrada en mapa debe poder consultarse también en:
- lista;
- tabla;
- texto.

## Testing
Automático + manual con teclado + screen reader antes de release.
