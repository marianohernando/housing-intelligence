# PRO Roles & Permissions

## Roles iniciales
- Owner
- Admin
- Analyst
- Viewer

## Capabilities
- manage_billing
- manage_members
- upload_private_data
- create_project
- edit_project
- run_analysis
- export
- view_sensitive_client_data
- manage_api_keys

## Regla
RBAC se valida backend-side.
Ocultar botones en UI no es seguridad.

## Project-level access
Enterprise puede limitar usuarios a workspaces concretos.
