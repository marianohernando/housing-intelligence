# Visión y Producto Maestro

## Visión
Crear una plataforma de inteligencia residencial que conecte:
**necesidad residencial → capacidad económica → territorio → oferta → inversión.**

## Pregunta PUBLIC
> ¿Qué vivienda necesito realmente y dónde puedo vivir mejor?

## Pregunta PRO
> ¿Qué vivienda necesita este territorio, dónde falta y qué producto debería crearse?

## Diferenciación
Los portales tradicionales parten de la oferta.
Nosotros partimos de la necesidad.

## Problemas atacados
- asequibilidad;
- búsquedas irreales;
- información dispersa;
- vivienda inadecuada;
- compra vs alquiler;
- ayudas desconocidas;
- coste real oculto;
- accesibilidad;
- necesidades de mayores;
- hogares monoparentales;
- familias numerosas;
- estudiantes;
- desajuste oferta-demanda;
- planificación territorial.

## Productos
### PUBLIC
Herramienta gratuita para resolver decisiones residenciales.

### PRO
Inteligencia territorial para empresas y administraciones.

### DATA
API + OpenAPI + MCP para software y agentes.
