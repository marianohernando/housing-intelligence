# Capas de Usuario Particular

## Objetivo
Mantener una capa gratuita realmente útil y, a la vez, crear una monetización opcional para usuarios intensivos sin convertir el producto en un paywall agresivo.

# 1. FREE

Debe permitir resolver el problema principal:
- crear perfil;
- affordability básica;
- recibir recomendaciones;
- mapa;
- score;
- Reality Check básico;
- ayudas;
- comparador limitado;
- evaluar un número limitado de escenarios/consultas IA.

## Monetización asociada
- SEO;
- AdSense en contenido editorial;
- afiliación opcional y separada;
- partners con opt-in.

Nunca insertar publicidad de forma que interfiera con el mapa o sesgue el ranking.

# 2. PLUS / PERSONAL PRO

Hipótesis de plan intermedio.

Posibles beneficios:
- más consultas conversacionales;
- más escenarios;
- historial;
- análisis de viviendas;
- comparaciones avanzadas;
- alertas;
- exportes;
- análisis de mudanza;
- mayor número de lugares de trabajo/familiares;
- simulaciones financieras;
- análisis personalizados.

## Regla
No limitar artificialmente información esencial de vivienda.
El pago compra:
- profundidad;
- volumen;
- automatización;
- seguimiento;
no una verdad distinta.

# 3. PRO B2B
Producto separado para profesionales.

No confundir PUBLIC PLUS con PRO inmobiliario.
