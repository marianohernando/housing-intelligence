# GDPR / Personal Data Lifecycle Design

## Lifecycle
collect → use → store → update → export → delete/anonymize.

## Principles
- minimization;
- purpose limitation;
- access control;
- retention;
- transparency;
- user rights.

## User controls
Production design must support:
- access/export;
- correction;
- deletion;
- consent/preferences;
- account closure.

## Personal data separation
Identity, financial profile, anchors and sensitive needs remain logically separated.

## Production legal review
Final lawful bases, notices and retention periods require legal review before public launch.
