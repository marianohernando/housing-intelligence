# Source License / Terms Review Workflow

For every non-trivial source record:
- owner;
- URL;
- license/terms;
- attribution;
- commercial reuse;
- derivative rights;
- storage limits;
- redistribution;
- automation/scraping permission;
- review date.

## Status
- CLEAR
- RESTRICTED
- PERMISSION_REQUIRED
- RESEARCH_ONLY
- REJECTED

## Gate
RESTRICTED/PERMISSION_REQUIRED cannot silently become production dependency.
