# Open Source Publication Policy

## DATAMAD objective
Show meaningful open-source implementation, not an empty wrapper.

## Publish candidate
- architecture;
- schemas/contracts;
- source catalog tooling;
- selected pipelines where licenses permit;
- scoring framework;
- API/MCP contracts;
- demo frontend/backend.

## Never publish
- secrets;
- private client data;
- restricted datasets;
- personal data;
- credentials.

## License
Final software license must be selected before public repository release after business/legal review.

## Dataset licenses
Software license does not override dataset licenses.
