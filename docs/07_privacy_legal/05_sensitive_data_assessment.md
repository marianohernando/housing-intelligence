# Sensitive Data / DPIA Readiness

## High-risk fields
- accessibility/disability-related needs;
- health-like context;
- precise home/work anchors;
- finances;
- family composition.

## Design
- opt-in where appropriate;
- explicit purpose;
- restricted service access;
- no ad targeting;
- no PRO individual exposure;
- audit logs;
- deletion.

## DPIA readiness pack
Maintain:
- data flow;
- purposes;
- risks;
- mitigations;
- providers;
- retention;
- access matrix.

Formal DPIA/legal determination occurs before production if required.
