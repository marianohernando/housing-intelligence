# DataMad Demo Runbook

## Goal
Demo is deterministic enough to rehearse but genuinely live.

## Sequence
1. open Madrid map;
2. enter natural-language profile;
3. show microzones;
4. explain one recommendation;
5. Reality Check;
6. accessibility example;
7. switch PRO;
8. Housing Gap 3D;
9. parcel/project;
10. MCP/dynamic analysis if stable;
11. source/lineage panel.

## For each step
Record:
- expected screen;
- query/input;
- expected response;
- fallback;
- max time.

## Reset
One command/button restores demo seed state.

## Rehearsal
Run exact flow repeatedly from clean state.
