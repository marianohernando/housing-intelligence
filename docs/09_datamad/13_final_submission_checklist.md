# DataMad Final Submission Checklist

## Product
- main flow works;
- no dead links;
- demo account seeded;
- feature flags set;
- reset scenario works.

## Data
- CM datasets clearly core;
- data manifest;
- attributions;
- freshness;
- snapshots.

## Code
- repository clean;
- README;
- setup;
- license;
- no secrets;
- tests pass.

## Jury evidence
- public value;
- economic value;
- environmental/social value where relevant;
- viability;
- open-source;
- data usage.

## Demo
- runbook;
- offline fallback;
- backup video/screen recording optional;
- local snapshot.

## Pitch
- problem;
- why current portals fail;
- solution;
- live demo;
- data/technical moat;
- impact;
- business;
- next step.
