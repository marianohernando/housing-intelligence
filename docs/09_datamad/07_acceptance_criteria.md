# DataMad Acceptance Criteria — Final-Product-First

## Core
- product boots from clean documented setup;
- core demo works on frozen snapshot;
- no critical external live dependency.

## Data
- meaningful CM datasets are central;
- each core metric has lineage;
- quality/freshness/confidence;
- no missing==zero mistakes.

## PUBLIC
- map-first scenario;
- natural language/chips;
- recommendations;
- explanation;
- Reality Check;
- inclusive accessibility example.

## Intelligence
- reproducible deterministic baseline;
- at least one real ML/embedding capability if enabled;
- JEV real if enabled;
- RAG real if enabled;
- all enabled capabilities passed their gate.

## PRO
- Housing Gap;
- site/thesis analysis;
- product recommendation;
- project/parcel experience.

## Map
- visually strong;
- progressive;
- 3D where stable;
- accessible textual alternative.

## MCP/API
- real tools;
- auth/contracts;
- provenance.

## Engineering
- CI green;
- no critical/high unresolved security issue for demo;
- demo smoke 10/10;
- backup/restore path;
- secrets clean.

## Open
- source code pack;
- data attribution;
- methodology.

## Transparency
Every important number is sourced or labeled modeled/estimated.
