# Sprint → Quality Gate Matrix

| Sprint | Fechas | Resultado obligatorio | Gates |
|---|---|---|---|
| P0 | 20–25 Oct | repo/CI/docs/data shortlist | G0 |
| P1 | 26 Oct–1 Nov | data foundation | G1–G2, start G3 |
| P2 | 2–6 Nov | competition-ready launch pack | G3 + G4 ready |
| S1 | 7–12 Nov | PUBLIC end-to-end | G4–G7 |
| S2 | 13–18 Nov | Intelligence + PRO + MCP | G8–G11 |
| S3 | 19–22 Nov | wow layer + system hardening | G12 candidate |
| S4 | 23–25 Nov | release/pitch/freeze | G12–G13 |
| Final | 26 Nov | presentation | smoke only |

## Rule
Un Gate no necesariamente espera al final del sprint.
Debe ejecutarse continuamente y cerrarse antes de dar el sprint por terminado.
