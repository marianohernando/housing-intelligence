# Scope Cut Registry

## Objetivo
Tener decidido antes de desarrollar qué recortar primero si falta tiempo.

## Orden inicial de recorte

### Cortar primero
1. Knowledge Graph dedicado.
2. Realtime transport completo.
3. Full 10-year scenario engine.
4. Financial return engine avanzado.
5. Full national-ready ingestion.
6. Exhaustive listing history.
7. Deep collaboration/team features.

### Mantener mientras sea posible
- 3D map;
- Residential Fit;
- Reality Check;
- accessibility;
- Place Model;
- Housing Gap;
- parcel/project analysis;
- MCP;
- explainability;
- data provenance.

## No cortar
- datos de Comunidad de Madrid;
- trazabilidad;
- core scoring;
- confianza/missingness;
- arquitectura correcta;
- tests mínimos del motor.

## Revisar semanalmente
Cada semana:
- estabilidad;
- coverage;
- performance;
- demo reliability;
- remaining engineering risk.
