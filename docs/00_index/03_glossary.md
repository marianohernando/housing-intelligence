# Glosario

**Affordability** — capacidad real de un hogar para asumir una vivienda.

**Residential Fit** — grado de encaje entre una zona/vivienda y las necesidades de un perfil.

**Housing Gap** — diferencia entre demanda residencial compatible y oferta compatible.

**GeoCell** — unidad analítica territorial interna, normalmente basada en H3.

**Feature Store** — conjunto versionado de variables derivadas listas para modelos y producto.

**Place Embedding** — representación vectorial de una zona basada en cientos de atributos territoriales.

**RAG** — recuperación de documentación relevante para ayudar al modelo generativo.

**JEV** — modelo orientado a decisiones tipadas rápidas, probabilísticas y con confidence.

**MCP** — interfaz para que agentes/modelos utilicen herramientas y recursos estructurados del sistema.

**Digital Twin** — representación geoespacial interactiva del territorio y sus capas de datos.
