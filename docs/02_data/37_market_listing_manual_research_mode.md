# Market Listing Manual Research Mode

## Objetivo
Permitir investigación limitada durante DATAMAD cuando una fuente de anuncios no permita automatización masiva.

## Modo manual
Un investigador puede registrar una muestra acotada de anuncios públicamente visibles y relevantes para:
- validar hipótesis;
- comparar tipologías;
- preparar demo;
- crear casos de prueba.

## Reglas
- no automatizar bypass de restricciones;
- no convertir muestra manual en dataset exhaustivo;
- registrar fecha y fuente;
- minimizar contenido copiado;
- guardar solo campos necesarios;
- no redistribuir contenido protegido;
- respetar condiciones de la fuente.

## Uso
La muestra manual es evidencia exploratoria, no backbone productivo.

## Camino preferido
1. API/feed/licencia/permiso;
2. partner autorizado;
3. fuente alternativa reutilizable;
4. muestra manual limitada para investigación.
