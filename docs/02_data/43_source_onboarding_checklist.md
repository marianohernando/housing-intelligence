# Source Onboarding Checklist

Before production:
- source registry entry;
- owner/provider;
- official URL;
- license/terms;
- allowed storage;
- commercial use;
- refresh cadence;
- geographic resolution;
- temporal semantics;
- schema;
- sample snapshot;
- parser;
- tests;
- lineage;
- quality thresholds;
- fallback;
- attribution text;
- source confidence.

No source is “integrated” until this checklist passes.
