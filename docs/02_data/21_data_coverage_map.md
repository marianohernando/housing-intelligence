# Data Coverage Map

## Objetivo
Representar dónde tenemos datos fuertes y dónde existen huecos.

## Dimensiones
- source coverage;
- freshness;
- geographic precision;
- temporal depth;
- agreement between sources;
- model dependence.

## Salidas
Por H3/microzona:
- overall_coverage;
- housing_coverage;
- mobility_coverage;
- services_coverage;
- environment_coverage;
- market_coverage.

## Uso interno
- priorizar scraping;
- priorizar nuevas fuentes;
- detectar zonas donde no debemos hacer afirmaciones fuertes.

## Uso PRO
Puede mostrarse como capa de calidad/metodología.

## Uso PUBLIC
No mostrar complejidad técnica; sí advertir cuando una recomendación tiene datos débiles.
