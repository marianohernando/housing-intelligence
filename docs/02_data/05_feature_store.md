# Feature Store

## Objetivo
Separar dato bruto de variable lista para producto/modelo.

## Tablas
- geo_features;
- area_features;
- building_features;
- parcel_features.

## Ejemplos
- school_access_score;
- healthcare_access_score;
- mobility_score;
- rent_affordability_index;
- senior_accessibility_score;
- green_access_score;
- noise_exposure;
- family_fit_base;
- housing_gap_base.

## Versionado
Cada feature:
- feature_version;
- calculated_at;
- source_version;
- formula_version.
