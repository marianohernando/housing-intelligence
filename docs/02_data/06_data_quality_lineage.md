# Calidad, Lineage y Versionado

## Checks
- nulos;
- outliers;
- tipos;
- unidades;
- duplicados;
- cambios de esquema;
- cobertura territorial;
- frescura;
- discontinuidades.

## Lineage
Cada valor derivado debe conocer:
- fuente;
- transformación;
- fecha;
- versión.

## Reproducibilidad
Cada recomendación debe poder reconstruirse con:
- data_version;
- feature_version;
- model_version;
- methodology_version.
