# Dataset Selection Scorecard

## Objetivo
Elegir 30–50 fuentes por valor real, no por facilidad.

## Criterios 0–5
- DATAMAD relevance;
- product impact;
- geographic granularity;
- temporal depth;
- freshness;
- coverage;
- quality;
- license clarity;
- ingestion difficulty;
- uniqueness;
- demo visibility.

## Score
Mantener score + notas; no usar suma ciega.
Una fuente puede entrar por ser estratégica aunque sea difícil.

## Output
- P0 ingest now
- P1 next
- P2 enrichment
- P3 research only
