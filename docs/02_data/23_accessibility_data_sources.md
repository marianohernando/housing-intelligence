# Accessibility Data Sources — Madrid

## Discapacidad visual / cruces
- Ayuntamiento de Madrid: semáforos con avisadores acústicos, actualización mensual.
- Dataset relacionado: avisadores acústicos a demanda.
- Cruces semaforizados para enlazar dispositivos y contexto.

## Aceras/calzadas
- Accesibilidad y movilidad en aceras y calzadas.
Limitación: refleja actuaciones de mejora, no certifica todas las aceras de Madrid.

## Flujo peatonal
- Aforos de peatones y bicicletas.
Uso como proxy parcial de intensidad/crowding, siempre con cobertura/confidence.

## Transporte
Investigar: ascensores, accesibilidad por estación, incidencias, intercambiadores y ayudas de orientación.
El CRTM inició en 2026 un piloto de mapa háptico en Plaza de Castilla con braille, pictogramas, alto contraste, audiodescripciones y audio.

## Accesibilidad cognitiva / sensorial
Fuentes directas serán limitadas. Usar proxies:
- ruido;
- intensidad peatonal;
- tráfico;
- complejidad de intersecciones;
- complejidad de rutas;
- transbordos;
- verde;
- actividad nocturna.

## Regla
`high_noise_exposure` es válido.
`bad_for_autism` NO es válido.
