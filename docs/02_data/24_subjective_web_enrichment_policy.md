# Subjective / Web Enrichment Policy

## Objetivo
Enriquecer conceptos como:
- vida de barrio;
- tranquilidad;
- actividad;
- comercio;
- ambiente.

## Prioridad de fuentes
1. oficial;
2. directorios/censos estructurados;
3. OSM/open data;
4. webs oficiales;
5. fuentes web secundarias con uso/licencia revisado.

## Internet/web puede aportar
- horarios;
- tipología;
- servicios;
- ocio nocturno;
- actividad/eventos;
- datos públicos ausentes del catálogo.

## Nunca
- reseñas sueltas como verdad;
- foros para seguridad;
- texto sin provenance;
- scraping prohibido.

## Derivación
Texto web → clasificación estructurada → confidence → feature/proxy.

No:
texto web → LLM inventa score.
