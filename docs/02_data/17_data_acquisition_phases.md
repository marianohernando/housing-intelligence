# Fases de Adquisición de Datos

## Fase A — Fundacional
Prioridad:
1. Comunidad de Madrid;
2. Ayuntamiento;
3. INE;
4. Catastro;
5. CRTM/GTFS;
6. datos.gob.es.

Objetivo:
producto funcional y defendible jurídicamente.

## Fase B — Open Enrichment
Añadir:
- OpenStreetMap;
- OpenAddresses si aplica;
- otros open datasets;
- directorios públicos estructurados.

## Fase C — API Enrichment
APIs comerciales/partners cuando:
- añadan frescura;
- añadan cobertura;
- tengan ROI.

## Fase D — Scraping ampliado
Solo después de:
- revisar términos;
- definir utilidad;
- crear parser robusto;
- evaluar coste de mantenimiento;
- asegurar fallback.

## Regla
“Podemos scrapearlo” no es suficiente para convertir una web en dependencia central.

## Objetivo futuro
Conseguir la máxima cobertura útil, no la máxima cantidad de filas.
