# Environmental History Specification

## Dominios
- air quality;
- noise;
- heat;
- weather;
- green;
- traffic exposure.

## Features temporales
- current;
- seasonal average;
- annual average;
- percentile;
- exceedance frequency;
- trend_1y;
- trend_3y.

## Objetivo
No decir “hoy hay poco NO2, luego la zona tiene buen aire”.
Modelar exposición habitual cuando exista histórico.

## Missingness
Cobertura de estaciones/sensores debe reflejarse en geographic confidence.
