Diseñar un universo amplio, pero no introducir variables inútiles.

Las cifras no se suman literalmente como obligación. Muchas features serán alternativas/versiones por resolución.

## Clasificación
Cada feature será:
- observed;
- derived;
- estimated;
- model_output;
- temporal_delta;
- contextual.

## Regla MVP
Solo entra una feature si:
1. tiene definición;
2. tiene fuente;
3. tiene test;
4. tiene utilidad;
5. tiene resolution policy;
6. tiene confidence/freshness.
