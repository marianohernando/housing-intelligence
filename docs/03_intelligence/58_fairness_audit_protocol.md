# Fairness Audit Protocol

## Objective
Avoid discriminatory housing recommendations and proxy effects.

## Tests
- score distribution by non-sensitive legitimate segments;
- accessibility-needs scenarios;
- geographic systematic exclusion;
- proxy feature review;
- platform-user sampling bias;
- investment vs social impact separation.

## Protected/sensitive characteristics
Do not use them to steer exclusionary residential marketing.

## Accessibility
Using explicit accessibility needs to improve an individual's own search is different from exposing sensitive cohorts to PRO.

## Gate
Any feature suspected as a sensitive proxy requires documented justification or removal.
