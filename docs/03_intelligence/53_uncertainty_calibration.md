# Uncertainty & Confidence Calibration

## Confidence is not “model vibes”.

Components:
- source;
- freshness;
- geographic resolution;
- coverage;
- model;
- disagreement.

## Model intervals
Prediction intervals must be evaluated for calibration.

Example:
An 80% price interval should contain actual values roughly 80% of the time on holdout data, within accepted tolerance.

## User-facing
Translate confidence into explanation.

## Gate
No confidence percentage is shown publicly unless calibrated.
Otherwise use qualitative labels + evidence.
