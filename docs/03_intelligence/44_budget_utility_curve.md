# Budget Utility Curve

Inputs:
- ideal_budget
- comfortable_budget
- absolute_max_budget

Comportamiento:
- <= ideal: sin penalización.
- ideal → comfortable: penalización pequeña.
- comfortable → absolute max: penalización creciente.
- > max: FAIL, salvo escenario alternativo explícito.

Reality Check puede simular +50 €, +100 €, +200 € y medir opciones nuevas.
