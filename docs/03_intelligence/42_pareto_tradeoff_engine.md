# Pareto / Trade-off Engine

## Objetivo
Mostrar soluciones de compromiso útiles.

## Salidas típicas
- Mejor equilibrio.
- Más asequible.
- Mejor movilidad.
- Más calidad de vida.
- Mejor para familia.
- Mejor accesibilidad.
- Alternativa inesperada.

## Regla
No decir “esta es la mejor zona” si existen trade-offs claros.

Ejemplos:
- “Esta equilibra mejor precio y trayecto.”
- “Esta cuesta menos, pero suma 12 min de viaje.”
- “Esta tiene peor transporte, pero gana mucho en espacio y tranquilidad.”
