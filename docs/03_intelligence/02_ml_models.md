# Modelos Machine Learning

## Modelos previstos

### Place Embedding
Autoencoder sobre 200–400 features territoriales.

### Ranking
Learning-to-Rank para ordenar zonas cuando exista feedback suficiente.

### Precio / alquiler
Gradient Boosting (LightGBM/CatBoost) con intervalos de incertidumbre.

### Demanda
Estimación de hogares compatibles por segmento.

### Forecasting
Hogares, envejecimiento, presión, demanda.

### Clustering
HDBSCAN / k-means sobre embeddings.

## Principio
Primero modelos explicables y robustos; complejidad solo cuando aporte valor.
