# Contextual Scoring Reference

## Objetivo
Evitar que un mismo valor se interprete igual en contextos urbanos muy distintos.

## Dos referencias

### Absoluta
Ejemplo:
- 8 minutos a Metro;
- 2 colegios en 15 minutos;
- alquiler 18 €/m².

### Relativa
Comparar con:
- Madrid total;
- municipio;
- cluster urbano similar;
- densidad comparable.

## Ejemplo PUBLIC
> “El acceso a Metro es bueno para Madrid y especialmente bueno para una zona residencial de esta densidad.”

## Regla
La comparación relativa nunca debe sustituir el dato absoluto.
