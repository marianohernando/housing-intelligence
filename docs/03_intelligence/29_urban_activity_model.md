# Urban Activity & Business Fabric Model

## Objetivo
Entender qué vida económica existe alrededor de una microzona.

## Inputs
- locales;
- categorías;
- aperturas/cierres;
- horarios;
- oficinas;
- empleo;
- densidad empresarial;
- equipamientos.

## Features
- business_density;
- category_diversity;
- essential_retail_access;
- hospitality_intensity;
- office_intensity;
- evening_activity;
- opening_velocity;
- closure_velocity;
- business_churn;
- employment_access.

## PUBLIC
Usos:
- vida diaria;
- ocio;
- conveniencia;
- tranquilidad vs actividad.

## PRO
Usos:
- madurez comercial;
- demanda;
- zona emergente;
- riesgo;
- servicios faltantes.
