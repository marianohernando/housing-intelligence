# Cold Start Strategy

## Problema
DATAMAD tendrá pocos o cero usuarios reales.

## Solución
Arrancar con:
1. datos públicos;
2. conocimiento experto;
3. perfiles sintéticos;
4. escenarios de test;
5. reglas explicables.

## Synthetic Profiles
Crear cientos/miles de perfiles sintéticos plausibles variando:
- ingresos;
- household;
- work anchors;
- tenure;
- priorities;
- mobility;
- constraints.

## Uso
- stress test;
- distribución de resultados;
- detectar scores absurdos;
- probar Reality Check;
- preparar demos.

## No usar
Perfiles sintéticos no sustituyen validación con personas reales ni son evidencia de demanda de mercado.
