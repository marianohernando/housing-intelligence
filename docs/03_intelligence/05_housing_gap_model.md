# Housing Gap Model

## Objetivo
Medir demanda residencial compatible no satisfecha.

## Concepto
Compatible Demand - Compatible Supply = Unmet Demand

## Segmentar por
- tamaño;
- dormitorios;
- precio;
- alquiler/compra;
- accesibilidad;
- household;
- ubicación;
- servicios.

## Salidas
- Housing Gap Score;
- hogares potenciales;
- tipología faltante;
- precio asumible;
- producto recomendado;
- confidence.
