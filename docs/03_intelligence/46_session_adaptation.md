# Session Adaptation

Señales:
- rechazo;
- guardado;
- filtros;
- texto;
- comparación;
- feedback explícito.

Cambios permitidos:
- pesos del escenario;
- preferencias;
- constraints confirmados;
- anchors;
- tolerancias.

No:
- inferir diagnósticos;
- cambiar modelo global por un clic;
- tratar un evento accidental como preferencia fuerte.
