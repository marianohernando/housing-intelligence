# Emerging Opportunity Model

## Objetivo
Detectar zonas que están cambiando antes de que el cambio sea evidente por precio.

## Señales
- crecimiento población/hogares;
- cambios de edad;
- evolución de renta;
- transacciones;
- alquiler;
- nuevas aperturas;
- cierres;
- nuevas infraestructuras;
- servicios;
- inversión pública;
- promociones/licencias;
- empleo.

## Motor inicial
No empezar con una red neuronal.

### MVP
Trend features + reglas + clustering + anomaly detection.

### Evolución
Supervised model cuando existan labels históricos adecuados.

## Output
- emerging_direction;
- drivers;
- trend_strength;
- confidence;
- risks.

## Regla
No convertirlo automáticamente en “compra aquí”.
Es intelligence, no recomendación financiera.
