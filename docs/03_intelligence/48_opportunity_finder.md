# Opportunity Finder

## Dos modos

### Site-first
“Tengo esta parcela. ¿Qué harías?”

### Thesis-first
“Quiero desarrollar 80–150 viviendas de alquiler familiar con buena conexión a Madrid.”

## Pipeline
1. parse thesis;
2. convert to constraints;
3. territory candidate generation;
4. demand/supply analysis;
5. gap;
6. parcel availability/context where possible;
7. rank;
8. explain;
9. create map layer.

## Output
- top territories;
- why;
- risks;
- recommended product;
- confidence;
- sources.
