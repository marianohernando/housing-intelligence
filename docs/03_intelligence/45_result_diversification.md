# Result Diversification

## Objetivo
Evitar cinco resultados casi iguales.

## Diversidad por
- geografía;
- trade-off;
- tipología urbana;
- banda de precio.

Ejemplo:
1. Mejor equilibrio.
2. Más barato.
3. Mejor conectado.
4. Más tranquilo.
5. Alternativa fuera de Madrid ciudad.

Aplicar minimum fit threshold.
