# PRO Project Simulation Engine

## Pregunta
> ¿Qué pasa si construyo 150 viviendas aquí, 2–3 dormitorios, a 1.250 €/mes?

## Input
- parcel/area;
- units;
- bedrooms;
- surfaces;
- target price/rent;
- tenure;
- amenities;
- delivery horizon.

## Engine
1. compatible household universe;
2. affordability filtering;
3. mobility fit;
4. competition;
5. existing + pipeline supply;
6. demand gap;
7. price sensitivity;
8. estimated absorption;
9. scenario impacts.

## Output
- estimated compatible demand;
- estimated absorption range;
- best/worst sensitivities;
- competitive context;
- service strengths/deficits;
- risk flags;
- confidence.

## Important
This is decision support, not a guarantee of investment return.

## Visual
SimCity mode can show:
- proposed project;
- demand catchment;
- flows;
- service coverage;
- before/after scenario.
