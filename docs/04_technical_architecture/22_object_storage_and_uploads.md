# Object Storage & Upload Security

## Store
- Bronze source files;
- user/client documents;
- generated reports;
- model artifacts;
- demo snapshots.

## Security
Uploads:
- size limit;
- MIME validation;
- extension mismatch detection;
- malware scan where available;
- no executable serving;
- signed URLs;
- tenant paths;
- retention.

## Document processing
Treat file content as untrusted.
No macros/code execution.
