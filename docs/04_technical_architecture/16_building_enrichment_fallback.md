# Building Intelligence — Enrichment & Fallback

## Nivel C objetivo
Para un edificio:
- geometry;
- cadastral/public attributes;
- age where available;
- use;
- context;
- services;
- accessibility proxies;
- technical docs available;
- modeled attributes clearly labeled.

## Fallback B
Si no existe cobertura:
- geometry;
- cadastral basics;
- surrounding microzone;
- no fabricated building-level attributes.

## Provenance
Cada campo debe indicar:
- observed;
- inferred;
- modeled.

## UI
No presentar una estimación territorial como si fuera información certificada del edificio.
