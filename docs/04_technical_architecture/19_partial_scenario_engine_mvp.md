# Scenario Engine — DATAMAD Reduced Scope

## MVP
Permitir escenarios parciales:
- añadir una promoción residencial;
- ajustar precio/unidades;
- simular una nueva estación o servicio en modo demo controlado;
- recalcular subconjunto de accesibilidad/demanda/gap.

## Producto completo
Recalcular más dependencias territoriales y comparar before/after.

## Regla
No fingir causalidad completa.
El MVP debe dejar claro qué variables recalcula y cuáles mantiene constantes.
