# ADR-002 — H3 como malla analítica

## Estado
ACCEPTED.

## Decisión
Mantener fronteras administrativas para UX y H3 para análisis.

## Motivos
- unión de datasets;
- ML;
- heatmaps;
- resoluciones jerárquicas;
- evita que todo dependa de barrios.

## Riesgo
Falsa precisión si una fuente es más gruesa.
Mitigar con resolución y confidence explícitos.
