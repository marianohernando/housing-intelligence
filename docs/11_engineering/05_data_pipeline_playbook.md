# Data Pipeline Playbook

## Al añadir una fuente nueva
1. Registrar source.
2. Registrar dataset.
3. Revisar licencia.
4. Crear fixture.
5. Escribir parser.
6. Tests de schema.
7. Normalizar.
8. Resolver geografía.
9. Entity Resolution.
10. Quality report.
11. Publicar Silver.
12. Mapear a métricas/features.
13. Añadir lineage.
14. Documentar.

## Definition of Done
No se considera integrada si solo “descarga el CSV”.
