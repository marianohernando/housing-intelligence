# Architecture Decision Records

## Ubicación
`11_engineering/adr/`

## Formato
- contexto;
- decisión;
- alternativas;
- consecuencias;
- estado;
- fecha.

## Cuándo crear ADR
- nueva base de datos;
- cambio de stack GIS;
- nuevo proveedor IA;
- nueva política de caching;
- cambio de geografía principal;
- cambio de autenticación;
- cambio de multi-tenancy.

## Estados
PROPOSED / ACCEPTED / SUPERSEDED / REJECTED.
