# AI Workflow Playbook

## Añadir una capacidad IA

1. Definir la decisión o tarea.
2. Preguntar: ¿puede hacerse en código?
3. Si sí, no usar IA.
4. Si es clasificación/decisión estructurada, evaluar JEV.
5. Si es retrieval, usar RAG.
6. Si es predicción, ML.
7. Si requiere síntesis/razonamiento, Claude/Fable.
8. Definir typed input/output.
9. Crear golden cases.
10. Eval.
11. Observabilidad.
12. Fallback.

## Regla
Nunca añadir un prompt sin test cases.
