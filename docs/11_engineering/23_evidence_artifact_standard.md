# Quality Evidence Artifact Standard

For each passed gate create:
`evidence/gate-XX/YYYY-MM-DD/`

Include as relevant:
- test summary;
- CI run/link/id;
- screenshots;
- dataset manifest;
- model eval;
- performance result;
- security result;
- manual checklist;
- known limitations;
- approver/decision.

## Why
The roadmap can then say “Gate 4 PASS” with evidence instead of relying on memory.
