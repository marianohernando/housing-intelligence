# Timeline / SimCity Mode

## Objetivo
Permitir “ver” cómo cambia Madrid.

## MVP
Comparar:
- años históricos disponibles;
- situación actual;
- forecast corto si existe.

## Producto completo
Slider:
2022 → 2023 → 2024 → 2025 → 2026 → 2027/2029 forecast → scenario.

## Capas animables
- población;
- hogares;
- alquiler;
- transacciones;
- negocios;
- servicios;
- transporte;
- Housing Gap;
- emerging opportunity.

## Scenario Mode
Añadir elemento hipotético:
- nueva estación;
- promoción;
- hospital;
- colegio.

Recalcular capas dependientes.

## UI
El usuario debe distinguir visualmente:
- OBSERVADO;
- ESTIMADO;
- FORECAST;
- ESCENARIO.
