# Estado Visual del Mapa

## Estados principales
- EXPLORE
- PROFILE_RESULT
- COMPARE
- REALITY_CHECK
- PRO_DEMAND
- PRO_SUPPLY
- PRO_GAP
- PARCEL_ANALYSIS

## Ejemplo PROFILE_RESULT
- mapa oscuro;
- zonas incompatibles desaturadas;
- top zonas iluminadas;
- cámara vuela a top 1;
- panel explica score.

## PRO_GAP
- H3 extruido;
- altura = unmet demand;
- color = severity;
- edificios contextuales semitransparentes.

## Regla
La misma variable no debe cambiar de significado visual entre pantallas sin leyenda explícita.
