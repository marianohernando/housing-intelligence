# Accessibility Map Modes

## Capas
### Visual
- avisadores acústicos;
- cruces;
- rutas con menor complejidad;
- transporte accesible;
- ayudas de orientación.

### Mobility
- ascensores;
- estaciones accesibles;
- pendientes;
- obras;
- rutas step-free;
- edificio con ascensor cuando exista.

### Cognitive/Sensory
- ruido;
- tráfico;
- aglomeración proxy;
- actividad nocturna;
- rutas simples;
- transbordos;
- verde.

## UX
No mostrar “Mapa de autismo”.
Mostrar “Menos ruido y rutas sencillas” o “Accesibilidad visual”.

## Confidence layer
Distinguir observado / proxy / sin cobertura.
