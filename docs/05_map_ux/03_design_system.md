# Sistema Visual

## Dirección
- fondo oscuro en modo intelligence;
- edificios gris carbón/translúcido;
- acentos luminosos;
- capas por intensidad;
- glass panels;
- cámara suave;
- animaciones discretas.

## Debe evitar
- estética gamer excesiva;
- brillo que impida leer;
- sobrecarga;
- depender solo del color.

## Accesibilidad
- contraste;
- estados alternativos;
- teclado;
- leyendas;
- patrones además de color.
