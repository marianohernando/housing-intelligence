# Mapa 3D / Digital Twin

## Objetivo visual
Combinar facilidad de uso con una experiencia:
**SimCity + Jarvis + digital twin.**

## Stack
- MapLibre;
- deck.gl;
- Three.js solo donde aporte valor.

## Capas
- H3;
- edificios;
- parcelas;
- transporte;
- servicios;
- heatmaps;
- columnas 3D;
- rutas;
- isócronas.

## Edificios
Aprovechar modelo 3D oficial de Madrid cuando sea viable.

## Modos
### Normal
Simple, legible, ciudadano.

### Intelligence Mode
Oscuro, 3D, capas avanzadas, holográfico.

## Regla
La espectacularidad no puede reducir usabilidad.
