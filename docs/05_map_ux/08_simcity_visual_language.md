# Lenguaje Visual SimCity / Jarvis

## Dirección
No fotorrealismo.
Representación estilizada y legible del Madrid real.

## Elementos
- edificios LOD2 gris grafito;
- bordes sutiles;
- microzonas iluminadas;
- H3 extruido en PRO;
- rutas animadas;
- POIs por iconografía minimal;
- halos para accesibilidad;
- transiciones suaves;
- cámara fly-to;
- profundidad atmosférica ligera;
- paneles flotantes.

## PUBLIC
Priorizar claridad.
La ciudad sirve para orientar y entender.

## PRO
Más densidad analítica:
- columnas;
- gaps;
- forecast;
- parcelas;
- comparación.

## SimCity
La inspiración debe sentirse en:
- lectura territorial;
- capas;
- “ciudad viva”;
- simulaciones.

No debe parecer videojuego ni sacrificar credibilidad.
