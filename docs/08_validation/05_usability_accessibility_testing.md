# Usability & Accessibility Validation

## PUBLIC user tests
Tasks:
- start without instructions;
- set budget;
- add work anchor;
- understand top results;
- change a preference;
- understand Reality Check;
- inspect confidence/source.

## Accessibility
Test with:
- keyboard only;
- screen reader;
- high zoom;
- reduced motion;
- color-blind safe legends.

## Success
Track:
- task completion;
- time;
- errors;
- comprehension;
- trust.
